Por equipe

Por semana

Semanas de domingo a sábado. Realizado e % da meta da semana.

Metas diárias por equipe

O nome tem que ser igual ao da coluna EQUIPE da planilha de produção.

Feriados

Meta zero para todas as equipes. Inclua os feriados municipais.

Fator sobre o realizado

Multiplica o valor das planilhas (ex.: 1,0295 para reajuste de 2,95%). Use 1 para não alterar.

Subir planilha de produção

Arquivos .xlsm ou .xlsx no modelo PRODUÇÃO (aba FORMULÁRIO). Pode selecionar várias de uma vez. Os dias de cada equipe que vierem no arquivo substituem o que já estava salvo.

Produção salva no mês

Liberar edição neste computador

Quem só abre o link vê tudo, sem configurar nada, e a tela se atualiza sozinha. Para editar, cole a chave de editor (token do GitHub) uma vez em cada computador. Depois disso, toda alteração é salva sozinha e aparece nos outros computadores em até 1 minuto.

Configuração avançada

Preenchido sozinho quando o painel é aberto pelo link do GitHub Pages.

Backup dos dados

Conteúdo atual do data.json. Dá para copiar e colar direto no arquivo do repositório.

Editar dia

Valor bruto, antes do fator. Deixe 0 para dia sem produção.
